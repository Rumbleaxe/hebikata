# Research

This directory stores research findings on best teaching methods for Python education, particularly for the HebiKata platform.

## Structure

- `exercises/` — Exercise design patterns, templates, schemas, and effectiveness studies
- `pedagogy/` — Learning theory, spaced repetition research, mastery learning findings, and references
- `results/` — Data and analysis from user studies, A/B tests, or experiments conducted on the platform

## Purpose

HebiKata's design (spaced repetition, themed exercises, immediate feedback) is grounded in pedagogical research. This folder versions the evidence and rationale behind those decisions, so future development remains informed by actual learning science rather than intuition.
